<strong>Explanation:</strong> As 10 * 40 = 400, the answer is true.
</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [-10, 20, 9, -40], target = 30

<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [-10, 0, 9, -40], target = 0
